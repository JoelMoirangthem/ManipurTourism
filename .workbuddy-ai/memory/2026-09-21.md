## Review pass — found and fixed 4 real defects

A self-review looking for loose ends turned up four genuine bugs, not cosmetics:

1. **PRIVACY LEAK — the thread page bypassed authorization.** `src/app/inquiries/[id]/page.tsx` called the *unscoped* `getInquiry(id)` and justified it in a comment as "reachable by direct link by design". Any visitor could read any thread by id — including a host's private replies — and anonymous readers saw it too. Fixed: the page now resolves the actor server-side and uses `getInquiryScoped`, rendering a refusal notice on `ScopeDenied`. Verified: anonymous → refusal, no thread content leaks; owner → thread renders.
2. **Implicit default-allow in `getInquiryScoped`.** It was an `if` chain handling only `visitor` and `provider`, so any other role (e.g. `reviewer`) fell through to unrestricted read. Rewritten as an explicit `switch` with a `default:` that denies, and the reviewer's allow is now a *stated* policy consistent with `listInquiries`.
3. **Wrong model attribution in `/api/translate`.** The response hardcoded `model: "gemini-3.6-flash"` while the call read `GEMINI_MODEL` from env — so changing the env var would make the API report a false model. That violates R31 (truthful provider/model metadata). Fixed by returning the model actually used.
4. **Mis-mapped WMO weather codes.** `weatherDescription` used coarse bands: code 3 (overcast) was labelled "partly cloudy", and the freezing variants (56/57 freezing drizzle, 66/67 freezing rain) were collapsed into plain drizzle/rain — hiding exactly the hazard that matters on hill roads. Rewritten against the real WMO 4677 table with an honest `unknown conditions` fallback.

Also: gave `nominatimLookup` its own identifying User-Agent and a ≤1 req/s gate (it was reusing the LLM gateway's UA, which misidentifies the app —a Nominatim policy violation waiting to happen). Removed three one-shot trace scripts; kept the genuinely reusable `debug-guard.mjs` and `inspect-answers.mjs`.

**New tests added:** `src/lib/__tests__/weather.test.mjs` (4 tests, all 28 documented codes; verified it FAILS on a reintroduced regression) and two page-level scope tests in `eval/api-tests.mjs` (now 28, was 26).
